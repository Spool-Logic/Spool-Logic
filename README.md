# Spool-Logic
Spool Logic is a **3D printing queue and shop manager** for hobbyists, designers, and small businesses — print queues, print history, printer organization, filament storage, and cost tracking. Easy to manage, minimal setup.
**[Try SpoolLogic (live app) →](https://spoollogic.streamlit.app/)**
