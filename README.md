# SpoolLogic

**3D print queue and shop manager** for hobbyists, makers, and small businesses — not automotive / turbo software.

SpoolLogic tracks print queues, print history, printers, filament, and costs. Shop data stays in your browser. Cloud is sign-in and billing only.

**[Try SpoolLogic (live app) →](https://spoollogic.streamlit.app/)**

**Pricing:** 14-day free trial · **$5.50/month** · unlimited printers · one plan
