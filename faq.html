SpoolLogic questions

Short answers for people (and search engines) deciding if this 3D print queue tool fits one machine at home or a small shop.

  • What is SpoolLogic?

    Local-first 3D printing software for everyone who 3D prints: queue, filament, and costs in the browser. It does not replace your slicer. It is not automotive turbo software.

  • Is it for one hobby printer or a print farm?

    Both. Same app, same $5.50/month plan, unlimited printers, no per-machine fee. Start with one printer; add more in Printer Management when you grow.

  • How do I manage multiple 3D printers?

    Give each machine a queue. Auto-assign uses the shortest queue. Balance All and suggested moves help when one printer is overloaded. You still press print on the machine.

  • How much does it cost?

    14-day free trial, then $5.50/month. After trial, view-only until you subscribe. Stripe handles payment.

  • Where is my print queue stored?

    In this browser, on this device. Files stay on your PC. Cloud is login and billing only. A new browser starts empty (by design).

  • Does it work with Bambu Lab / Bambu Studio / OrcaSlicer?

    Yes as a queue and file-link layer (AMS-style slots, .3mf, drag into the slicer in Chrome/Edge). Not a live network driver and not Bambu Farm Manager.

  • Can I track filament and costs without a spreadsheet?

    Yes: $/kg, slot grams, ~100g warnings, material + machine time + waste, optional profit records. Lag-rate slider stretches the timeline if you are not printing 24/7.

  • Is this Spoologic turbo kits or Spoolman?

    No. This is SpoolLogic 3D print queue software (GitHub: Spool-Logic). Unrelated to diesel turbo brands and unrelated to Spoolman/SpoolEase.
